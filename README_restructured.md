# EPFL Machine Learning Project 1

## Project layout

Keep the submitted repository organized around the course requirements:

```text
project1/
├── README.md
├── run.ipynb                 # restructured, reproducible workflow
├── implementations.py        # six required course method implementations
├── helpers.py                # course-provided data/submission helpers
├── dataset/
│   ├── x_train.csv
│   ├── y_train.csv
│   └── x_test.csv
├── submission.csv            # generated by the notebook; do not hand-edit
└── report.pdf                # maximum two pages (references may use page 3)
```

## Workflow

1. Load the data and perform exploratory analysis.
2. Document preprocessing assumptions and fit preprocessing on training partitions only.
3. Run the holdout experiments as exploratory comparisons.
4. Compare the candidate SGD variants using the same stratified five-fold splits and collect out-of-fold probabilities.
5. Select the model variant and decision threshold, refit on all labeled data, and generate `submission.csv`.
6. Summarize baselines, the most impactful ablations, metrics, and limitations in the report.

## Run

1. Place `x_train.csv`, `y_train.csv`, and `x_test.csv` in `dataset/` without renaming them.
2. Ensure `helpers.py` and `implementations.py` are in the project root.
3. Open `run.ipynb` and run all cells from a fresh kernel.
4. Check that `submission.csv` is created and contains predictions for the test rows.

## Course constraints and reproducibility

- Use only the Python standard library and NumPy for computation. Visualization libraries such as Matplotlib are permitted for visualization only.
- Do not use pandas, scikit-learn, PyTorch, TensorFlow, external ML libraries, or external datasets.
- Keep all six required method implementations in `implementations.py`, with the required signatures and return values specified in the project handout.
- Fit preprocessing separately within each training fold; never fit imputation, feature selection, or scaling using a validation fold or the test set.
- Report cross-validation and baseline results rather than relying only on the online leaderboard.
- Record the preprocessing threshold, regularization, learning rate, training iterations/epochs, weighting choice, fold count, random seeds, and decision threshold used for the final submission.
